# EventSpark client

React 19 single-page app built with Vite, Tailwind CSS, and React Router.

## Run locally

```bash
npm install
npm run dev
```

The Vite development server proxies `/api` requests to `http://localhost:5000`.
Start the Express server and local MongoDB first; see the [project README](../README.md)
for setup, API routes, and GitHub publishing instructions.

## Pages

The app includes the welcome splash, festival home/countdown, login/signup, event catalog and
details, event registration, organizer event creation and management, sponsors,
gallery, contact/helpdesk, schedule, about, speakers, and FAQ pages.
